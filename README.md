# Currículum web - Dylan Morquecho Crow

Proyecto personal desarrollado con HTML5 y CSS3 para la actividad académica.

## Archivos
- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos y diseño adaptable a celulares.
- `img/fotografia.jpg`: fotografía personal (pendiente de agregar).

## Cómo abrirlo
Abre `index.html` con un navegador web.

## Agregar la fotografía
1. Coloca tu fotografía dentro de la carpeta `img`.
2. Nómbrala exactamente `fotografia.jpg`.
3. La página mostrará automáticamente la fotografía en el espacio reservado.

## Publicar con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `mi-curriculum`.
2. Sube `index.html`, `styles.css` y la carpeta `img`.
3. En el repositorio entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección tendrá el formato:
   `https://TU-USUARIO.github.io/mi-curriculum/`

## Antes de entregar
- Reemplaza la fotografía de ejemplo por una tuya.
- Comprueba que el enlace público abra sin iniciar sesión.
- Comparte el enlace al repositorio público.
- Revisa y corrige cualquier dato de experiencia o proyecto que no describa exactamente tu participación.
